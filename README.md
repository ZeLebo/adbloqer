# Adbloqer

Расширение отключает рекламный модуль поддерживаемого видеоплеера. Работа проверена на первом плеере NewDeaf. Версия для Search действует на страницах и во фреймах `https://ceramet.net/bil/*`. Версия для Zen и Firefox распознаёт тот же движок по структуре конфигурации на HTTPS-страницах.

## Установка

### Search Browser

1. Скачай и распакуй `adbloqer-1.0.0-search.zip` со страницы [релизов](https://github.com/zelebo/adbloqer/releases).
2. Открой **Settings → Extensions → Load an unpacked extension → Choose…** и выбери папку с `manifest.json`.
3. Подтверди доступ к `ceramet.net`. Обнови страницу с видео и запусти поддерживаемый плеер.

### Zen Browser и Firefox

1. Скачай `adbloqer-1.0.0-zen.xpi` со страницы [релизов](https://github.com/zelebo/adbloqer/releases).
2. Для временной установки распакуй XPI как ZIP. Открой `about:debugging#/runtime/this-firefox` → **Load Temporary Add-on…** и выбери распакованный `manifest.json`. Дополнение действует до перезапуска.
3. Для постоянной установки в Zen, который уже принимает неподписанные пакеты, открой `about:addons` → шестерёнка → **Установить дополнение из файла** и выбери XPI. Для обычной постоянной установки в Firefox нужна подпись Mozilla.
4. Перезагрузи страницу с плеером без кэша (`⌘⇧R` на macOS).

## Как работает

В Search скрипт подключается до запуска плеера. Он проверяет `window.playerData` и `window.adsConfig` и отключает рекламные флаги после распознавания движка. Сетевой фильтр Search можно использовать одновременно с Adbloqer.

В Zen и Firefox расширение просматривает начало HTML-ответов основных страниц и фреймов.
Распознаёт плеер по исполняемым встроенным JSON-конфигурациям
`window.playerData` и `window.adsConfig`, проверяет их структуру и добавляет
в рекламный конфигурационный скрипт локальный код до запуска загрузчика.

Код удерживает `window.dConf.showRadish` и `window.adallow` в `false`.
В исследованной сборке это завершает инициализацию рекламного модуля до
создания VAST/VPAID, баннеров и рекламных таймеров. Адреса видео, плейлисты,
субтитры, настройки качества и исходный код плеера сохраняются.

Для Zen и Firefox нужны разрешения `https://*/*`, `webRequest` и `webRequestBlocking`. Для Search достаточно доступа к `ceramet.net`. Обе сборки работают локально, без телеметрии или загрузки удалённых правил.

## Границы

- Поддерживается исследованный движок, а не любые видеоплееры. При смене его
  рекламного контракта обработчик потребуется обновить.
- Посторонний или нераспознанный HTML проходит без изменений. Сетевые ответы
  видео, плейлистов, JavaScript, изображений и API не фильтруются.
- В Zen и Firefox просмотр ограничен первыми 64 KiB и одной секундой с первого полученного
  блока. Если конфигурация не распознана за это время, ответ проходит как есть.
  Этот предел ограничивает задержку на обычных страницах.
- В Zen и Firefox HTML с CSP-хешами скриптов и с явно указанной кодировкой, отличной от UTF-8
  или US-ASCII, не изменяется. Политики CSP не ослабляются.
- Расширение не вырезает рекламу, вшитую в сам видеопоток.

## Проверка

```sh
node --test
node scripts/check-browser.cjs
```

Первая команда проверяет обработку потоков: сохранность байтов, разбиение
UTF-8 между блоками, ошибки, тайм-аут и ограничение размера.

Вторая команда запускает headless Zen с отдельным временным профилем и
локальным сервером. Текущий профиль пользователя не используется. Внешние
соединения тестового профиля направлены на неработающий локальный прокси;
тестовый сервер доступен напрямую. Проверяется нативный HTML-парсер,
неизменность конфигурации видео и отключение рекламных переключателей.
Для другого бинарного файла Firefox/Zen установить `ADBLOQER_BROWSER`.

Если рядом лежит `player-full.har`, браузерная проверка также использует
HTML и исходные методы рекламного модуля из захвата: оригинал должен дойти
до рекламной инициализации, обработанный документ должен её пропустить.
Содержимое HAR не включается в XPI. HAR может содержать данные сессии;
файлы `*.har` исключены из Git.

Эти проверки не заменяют проверку установленного расширения на живом плеере.
После установки запустить видео, переключить 720p → 1080p, выполнить паузу и
перемотку. Видео должно продолжать работать без рекламных вставок и повторов
запросов к VAST/VPAID. Фоновая консоль расширения пишет
`[Adbloqer] Player HTML prepared` после подготовки распознанного HTML;
это сообщение само по себе не подтверждает воспроизведение.

## Упаковка

```sh
mkdir -p dist
zip -X dist/adbloqer-1.0.0.xpi manifest.json player.js background.js
```

XPI содержит только эти три файла. Это неподписанный локальный пакет.
Постоянная установка через `about:addons` возможна, если Zen уже допускает
неподписанные расширения. Для проверки без изменения настроек подписи
использовать временную установку через `about:debugging`.

API браузера: [filterResponseData](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/webRequest/filterResponseData),
[StreamFilter](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/webRequest/StreamFilter).
